# PyGame Sorting Algorithm Visualizer
I wrote this in one night cause I got bored and thought it would be funny to write a sorting algorithm.

### Requirements
All the requirements are in `requirements.txt` but the most notable ones are the following. This visualizer may also work on older versions of these packages but I'm not sure.
```
 - pygame: 2.6.1
 - scipy: 1.17.1
 - numpy: 2.3.1
```
